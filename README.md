# Stressless Locale Switcher

A Chrome extension for quickly switching locales on stressless.com and shop.stressless.com (31 locales including /global).

## Installation

1. **Download & unzip** — Save the `stressless-switcher.zip` file and unzip it to a permanent folder on your computer.
2. **Open Chrome Extensions** — Type `chrome://extensions` in your address bar and press Enter.
3. **Enable Developer Mode** — Toggle on "Developer mode" in the top-right corner.
4. **Load the extension** — Click "Load unpacked" and select the unzipped `stressless-switcher` folder.
5. **Pin it** — Click the puzzle piece 🧩 in Chrome's toolbar and pin the extension for easy one-click access.

## Keyboard Shortcuts

| Action | Shortcut / How |
|---|---|
| Open the switcher | `Alt + Shift + L` (customisable) |
| Filter locales | Just start typing a country name or code |
| Cycle through results | `Tab` / `Shift+Tab` or `↑↓` |
| Go to locale | `Enter` or click any row |
| Jump to favourite | `1`–`9` (when search box is empty) |
| Close without switching | `Esc` |

## Favourites & Ordering

Star your most-used locales to build a personal shortlist and jump to them instantly with number keys.

- Hover any locale row in the **Switch** tab — a ★ appears on the right. Click it to favourite.
- Favourited locales appear at the top of the Switch tab, numbered 1–9.
- Press `1`–`9` when the switcher is open (and search is empty) to instantly navigate to that favourite.
- Open the **Manage** tab to drag rows into your preferred order, or click × to remove a favourite.

## Changing the Keyboard Shortcut

1. Open the **Manage** tab and click the link to `chrome://extensions/shortcuts`.
2. Find "Stressless Locale Switcher" and click the pencil icon next to "Open Stressless Locale Switcher".
3. Press your preferred key combination to save it.
